# Riddhima Kapoor | Portfolio (olive green edition)

One self-contained page. All pictures are embedded, so it works from any folder.

- `index.html` is the whole site (the file GitHub Pages serves).
- `.nojekyll` stops GitHub from processing the files.

## What changed from the desktop version
- Plain olive green backdrop with two soft glows that drift to a new spot on each slide. No folders or thumbnails on the landing page.
- Each content block is a floating frosted rounded rectangle with a thin white border and a soft glow. No window bar.
- The bottom bar has one flat line icon per section (8 in total). The current section's icon expands to show its name.
- Snap scrolling: one flick of the wheel moves exactly one slide, and trackpad inertia is ignored. Arrow keys, Page Up/Down, Space, Home and End also jump slide by slide. Phones and small windows use a gentler native snap because the panels flow taller than the screen.

## Open locally
Double-click `index.html`.

## Deploy on GitHub Pages
1. Create a public repository (e.g. `portfolio`).
2. Upload `index.html` and `.nojekyll` to the repository root.
3. Settings > Pages > Source = "Deploy from a branch", Branch = `main`, folder = `/ (root)`, then Save.
4. The site goes live at `https://<your-username>.github.io/<repo-name>/` after about a minute.
